# Common-base practices audit

- **Repository:** `human-review-console`
- **Catalog id:** Hrz7, including the case, clock, and workflow scope
- **Standard:** [`common-base-practices.md`](https://github.com/portable-genai/.github/blob/main/common-base-practices.md)
- **Applicability:** Hrz7 is a deterministic, stateful horizontal control-plane service with a web
  UI and Terraform. It contains no LLM, retrieval, generated claims, or owned login flow.

Verdicts were established from current code, commands, and the complete local gates, not copied
from the central matrix. Load-bearing checks are A1 through A6, C1 through C5, D1 through D3, and
E1. The case, clock, and workflow scope is covered wherever the evidence names `domain/cases`,
case ports, case API, case tests, Cloud Tasks, Pub/Sub, or the shared audit sink.

Documented limit, not a claim: with `REVIEW_PROFILE=local` chosen deliberately and `REVIEW_S2S_TOKEN` unset, `/v1/service/*` is unauthenticated. The commons shared-secret path returns without enforcement when the secret is unset (the zero-secret offline path), so this is bounded by exposure, not by authentication. ## Verdict summary

31 PASS, 1 PARTIAL, 0 FAIL, 9 N-A across 41 checks. Every applicable load-bearing check passes.
C3, C4, and E1 are N-A because the service has no LLM or agent boundary; they are not hidden
failures. The single remaining PARTIAL is D5, and only its live-enforcement half: the perimeter,
the residency allowlist, CMEK, Org Policy and the posture alerts are all coded and offline-tested,
but no named production project exists to prove enforcement on. Nothing else in this repository
can move that row.

## Catalog reconciliation

The Hrz7 capability row should not carry `F2/F3`, `G3/G5`, or
`docs/practices-audit.md projection missing` as gaps. It must retain
`ADK agent n/a (control-plane)`.

B4 policy-default configuration, C6 complete UI CSP/HSTS, C9 external local audit anchor, D4
multi-stage healthchecked image, and G2 adopter-owned regulator crosswalk are all PASS, each
backed by a test that can go red. The D5 posture (VPC-SC dry-run-first, posture alerts,
app-load residency validation, offline Terraform CI) is coded and tested; the row stays PARTIAL
until a named deployment can evidence live enforcement. No Hrz3 or Hrz5 application dependency
blocks this evidence projection or these local quality proofs.

Two honest limits worth carrying forward rather than hiding: the UI CSP keeps `'unsafe-inline'`
for Next.js's un-nonced bootstrap script and styles, and the local audit anchor defends against a
truncated tail but not against an attacker who can rewrite the database AND the anchor together.
